    在设置按钮左侧 增加 一个 信息按钮
    
    信息页面的要求：
        类似于 设置页面 背景毛玻璃特效 基本 一致

    Server信息：
        显示 服务的url 地址，例如 http://127.0.0.1
        显示 一些 http://127.0.0.1/config/mate 的 内容
        例如 服务版本 服务器时间 服务已运行时间
    
    API信息：
        显示 {line_key} {view}
        显示 frame_width， frame_height，org_width, org_height (图像尺寸， 原图 尺寸)
        
        http://127.0.0.1/api/{line_key}/health

    公司
        描述 版权 授权状态 等 信息，以及公司 官网 https://iet.ustb.edu.cn

    api 中没有的部分进行补齐
